# Code of Conduct

We want Locksmith to be a welcoming project for everyone who takes part, in issues, pull requests, discussions and any other project space.

## Our standard
- Be respectful and assume good faith.
- Give and accept constructive feedback; criticise ideas and code, not people.
- No harassment, discrimination, personal attacks, trolling, or publishing others' private information.
- Keep security discussions responsible: report vulnerabilities privately (see [SECURITY.md](SECURITY.md)).

## Enforcement
Maintainers may edit or remove contributions that break this code, and may temporarily or permanently ban anyone whose behaviour harms the community. To report a problem, contact the maintainers privately through a GitHub Security Advisory draft or by messaging the repository owner on GitHub; reports are handled confidentially.

This code is adapted in spirit from the Contributor Covenant 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
