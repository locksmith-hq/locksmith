# Icons

Every raster here is generated; edit the SVG source and regenerate, never the PNGs.

| Files | Source | Command (from `apps/desktop`) |
| --- | --- | --- |
| `32x32.png`, `64x64.png`, `128x128.png`, `128x128@2x.png`, `icon.png`, `icon.icns`, `icon.ico` | `src-tauri/icons/app-icon.svg` (vault-dial mark, dark variant: `packages/ui/brand/app-icon-dark.svg`, generated by `packages/ui/brand/gen.py`) | `npm exec --workspace @locksmith/desktop -- tauri icon src-tauri/icons/app-icon.svg`, then delete the generated `android/`, `ios/`, `Square*Logo.png` and `StoreLogo.png` (not shipped on macOS or Linux) |
| `tray/unlocked.png` (18 px), `tray/unlocked@2x.png` (36 px) | `packages/ui/brand/tray-unlocked.svg` | `npm exec --workspace @locksmith/desktop -- tauri icon ../../packages/ui/brand/tray-unlocked.svg -o src-tauri/icons/tray/unlocked --png 18,36`, then rename `18x18.png` / `36x36.png` |
| `tray/locked.png` (18 px), `tray/locked@2x.png` (36 px) | `packages/ui/brand/tray-locked.svg` | same, with `tray-locked.svg` and `-o src-tauri/icons/tray/locked` |

The tray PNGs are black-on-transparent template images: `tray.rs` embeds the @2x files and sets
`icon_as_template(true)`, so macOS tints them for the menu bar.
