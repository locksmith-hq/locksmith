# Design: M10d

## D1. Source is a hint, not an identity
Any process at the user's uid can name its binary `claude`. `source` and `host` are display hints
and never feed authorization; the lease's trust still comes from the kernel parent walk (M3) and
the attested caller. Labels and `root_exe` are cleaned (control characters dropped, length capped)
because a hostile process name could otherwise put escape sequences into `smith status`.

## D2. Detection inputs
- Agent-started lease: the root is the agent process (M10b D4). `source` comes from the root's
  executable path (`ls_platform::proc::exe_path`: `proc_pidpath` on macOS, `/proc/<pid>/exe` on
  Linux). Never arguments or environment, which can hold secrets.
- Human-started lease: the root is `smith session start` itself and the agent is spawned only after
  the daemon replies, so the root executable says nothing. `source` comes from the first word of the
  agent command the human typed (`SessionStart.command`). This is request data from an attested
  `smith`, not a kernel fact; it is a display hint like the command itself.
- `host`: the nearest of up to 8 ancestors whose executable matches the host table. The walk stops
  at pid 1, at an unreadable hop, or at a parent younger than its child (recycled pid).
- Computed once at lease start and stored on the lease. `info()` never re-reads a pid, which could
  have been reused by then.

## D3. Tables
Two static tables in `ls-broker::source`, first match wins: agents and hosts, so a terminal never
becomes the source. Matchers: a fixed path fragment (Claude Code shipped by the desktop app under
`Library/Application Support/Claude/claude-code/`), an app bundle directly inside an
`Applications` directory (`Claude.app`, `Cursor.app`, `Visual Studio Code.app`, JetBrains IDEs),
and exact executable names (`claude`, `codex`, `cursor-agent`, `grok`, `gemini`, `aider`, ...).
Path rules come first so a helper inside a bundle belongs to its app. No fuzzy matching: `my-claude`
is `other: my-claude`. A host equal to the source label is dropped.

## D4. Self-report
`agent` and `model` are optional on the request (serde default: an older MCP server still works).
The daemon is the trust boundary: each must be 1 to 64 bytes of printable ASCII (0x20-0x7E), else
`BadRequest` before any other check. `locksmith-mcp` maps an empty string to "not reported". The
values are stored in `LeaseInfo.report` with `reported: true` and appended to the SESSION_START
audit rule as `reported agent="..." model="..."`; no new ledger column (the hash chain is unchanged).

## D5. Compatibility
New `LeaseInfo` fields are `#[serde(default)]` so a new client parses a status from an older daemon
(`source.kind = unknown`, `started_by = human`). TypeScript types are regenerated by ts-rs
(`just api-types`); CI checks they are in sync.
